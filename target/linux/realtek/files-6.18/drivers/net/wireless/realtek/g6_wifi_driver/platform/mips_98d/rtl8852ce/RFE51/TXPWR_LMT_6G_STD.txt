//			1. @@DomainCode=xx,  Regulation=xx

//			   @@CountryCode=US, Regulation=C9
//

//	(4)	If want to disable Tx power limit for one DomainCode or CountryConde, you can write "NONE" in Regulation.

//			2. @@CountryCode=xx,  Regulation=NONE

//		ex.
